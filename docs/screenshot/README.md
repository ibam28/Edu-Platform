# Screenshots

Reference screenshots of the LearnCode prototype (v0.0.1) running locally via Docker Compose.

All screenshots were captured at **1920×894 viewport**, English locale, against the
local development stack (`http://localhost:3000`).

## Authenticated state

| File | Description |
| --- | --- |
| `01-home-hero.png` | Home page hero — "Learn programming. Build skills. Become career-ready." tagline, Start Learning CTA, Register Free button, and platform illustration. Prototype v0.0.1 disclaimer visible at the bottom of the hero. |
| `02-vision-journey.png` | Vision page — "From Education to Employment" seven-step journey visualization (Learn → Practice → Build → Assess → Certify → Portfolio → Employment). Captured in logged-out state. |
| `03-dashboard-student.png` | Student dashboard (authenticated as `student@test.com`) — Profile card with display name and role, Continue Learning widget showing current Stage 0 progress (4/8 lessons), Progress Overview card, and Your Learning Path snapshot. |

## Notes

- These screenshots reflect the v0.0.1 prototype. Subsequent iterations may
  change the exact layout, copy, or component composition.
- The platform tagline is **"Learn programming. Build skills. Become career-ready."**
  (English) / **"Platform belajar pemrograman untuk membangun keterampilan dan
  siap berkarier."** (Indonesian).
- Production-blocker disclaimers (e.g. "Prototype v0.0.1 — concept validation, not
  a final product") are intentionally visible in the hero.
