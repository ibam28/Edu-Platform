# Project Master Blueprint

> Status: Draft skeleton. Authoritative sections are filled in as milestones are implemented.

## Vision

A programming education, certification, and talent platform with bilingual
(Indonesian / English) content that takes learners from guided lessons to
verifiable certification and connects verified talent to employers.

## Master Roadmap

1. Prototype v0.0.1 (M00 - current)
2. Validation
3. Funding
4. Commercial MVP
5. Certification + Talent + Recruitment

## High-Level Product Pillars

- Bilingual learning content (Indonesian and English).
- Structured courses, lessons, and demo assessments.
- Certification and talent/recruitment marketplace.
- Payments, AI-assisted learning, and code sandbox (future).

## Principle of the Blueprint

The blueprint evolves with each milestone. Content in this file is only trustworthy
for the milestone explicitly listed next to it. Unimplemented areas are marked as
future work and must not be treated as implemented capabilities.

## Current Milestone Context

- Current: **M00 - Project Foundation** (Prototype v0.0.1).
