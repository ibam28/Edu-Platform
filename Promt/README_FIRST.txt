AI CODER MICRO-PROMPTS — PROTOTYPE v0.0.1

Purpose
-------
This package breaks Prototype v0.0.1 into small, sequential AI coding tasks.
Each milestone folder contains several prompts. Upload ONE .txt file at a time
to the AI Coder and ask it to read and execute the prompt inside that file.

IMPORTANT WORKFLOW
------------------
1. Start with 00_PROJECT_FOUNDATION-01.
2. Upload one prompt file at a time.
3. Do not upload the whole ZIP to the AI Coder.
4. Let the AI Coder finish, test, and report the current prompt.
5. Review the result before moving to the next prompt.
6. Never ask the AI Coder to execute the whole folder at once.
7. If a prompt fails, create/follow a fix prompt before continuing.
8. Preserve the master project documentation as source of truth.

CONTEXT RULE
------------
Each prompt specifies which documents to read. The AI Coder must NOT recursively
read the entire repository or all documentation unless explicitly required.

TARGET
------
Prototype v0.0.1 only.

FINAL PRODUCT FEATURES SUCH AS:
- paid courses
- real certification issuance
- payment gateway

- recruitment

- advanced AI agents
- production-scale code execution
- mobile app
are OUT OF SCOPE for this prototype unless a prompt explicitly says otherwise.
